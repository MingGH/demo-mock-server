平台 基础通知 Web Push 角标
iOS 为什么晚了 8 年？Android 从 2015 年就支持 Web Push，苹果直到 2023 年 3 月的 iOS 16.4 才跟上，而且附带一个硬条件：只有「已添加到主屏幕」的 App 才有推送。所以大量 iPhone 用户以为自己收不到通知，实际是没把网站装到桌面。

Safari 为什么不支持静默推送？Apple 的官方文档写得很直白：不支持「不可见推送」，而且如果你的 Service Worker 收到推送后不立刻显示通知，Safari 会直接撤销你这个站点的推送权限。对比 Chrome，Safari 把「必须让用户看见」写成了惩罚条款。

静默推送意味着什么？理论上，网站可以在用户完全不知情的情况下往你的电脑里送数据并执行代码——后台同步、预缓存、上报埋点。正因如此，它也是各厂商防守最紧的地方：注册 Service Worker 需要用户手势，权限一旦被拒就再也拉不回来。

角标为什么各家不一样？Android 的未读角标是系统自己画的，浏览器根本不给你这个 API。桌面端只有 Chrome / Edge 装成 PWA 后才能用 setAppBadge。Safari 和 Firefox 桌面版压根不支持 Badging API。

通知按钮是好事还是坏事？技术上它让用户不用点进页面就能做决定，钓鱼和误触的绝佳载体也在这里——用户以为自己在系统层做选择，其实是在给一个网页授权。所以这四项能力本页都标为「需实际发送后确认」，不预先替你下结论。
