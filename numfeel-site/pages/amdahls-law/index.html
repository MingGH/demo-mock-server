🧮 墙是怎么砌起来的
S(n) = 1 / ( s + (1 − s) / n )

s 是串行比例，n 是核心数。分母里的 s 永远除不掉，所以 n 拉到无穷大， 加速比也只能逼近 1/s。串行 25%，天花板就是 4 倍——你烧再多的钱， 只是在逼近它，永远踩不到它。

这个公式叫阿姆达尔定律，Gene Amdahl 在 1967 年发表。当年没人在意： 那会儿 CPU 主频一年涨一半，谁需要并行。2004 年前后主频撞上功耗墙， 全行业转头堆核数，这个半个多世纪前的公式才变成每个架构师头顶的墙。

砸穿它的方法只有一个：回过头优化那个 s。demo 里的「优化代码」按钮 每点一次串行减 1%——真实世界里，这一下往往比你想象中贵得多。

定律出处：G. M. Amdahl, Validity of the Single Processor Approach to Achieving Large Scale Computing Capabilities, AFIPS 1967
