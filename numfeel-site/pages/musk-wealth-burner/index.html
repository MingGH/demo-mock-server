为什么他根本输不光？

这不是「能挺多久」的问题，是「会不会破产」的问题。带负漂移的随机游走，永不破产的概率大于 0。首次触及 0 的概率为：

P(破产) = exp( -2·edge·W / B )

把马斯克的 W = $1.3万亿、百家乐优势 edge = 1.2%、台面顶限 B = $130万 代入：指数 = -2×0.012×1.3e12 / 1.3e6 = -24000，P = e⁻²⁴⁰⁰⁰ ≈ 0。

反过来说，要让他有 50% 概率破产，每手得压 $450亿——是台面顶限的 3.5万倍。台面上限本身就是答案：它把 B 钉死在安全区，让庄家优势靠海量重复兑现，而不是靠搞垮某条巨鲸。

E[破产手数] ≈ W / (B·edge) = 1.3e12 / (1.3e6 × 0.012) = 8333万手 ≈ 158 年

彩蛋：按台面顶限玩一整年，期望亏 $82亿；而马斯克单小时身家波动常态约 $1600亿。赌场玩一年的负 EV，还不够特斯拉一小时的股价噪音。
