04 结论：为什么 REST 仍是主流
GraphQL
  • 客户端精确取数，省流量
  • 一次请求拿完嵌套数据
  • 代价：服务端成本无上界
=
REST
  • 接口即契约，成本可预估
  • GET 天然可缓存、幂等
  • 代价：字段冗余（可优化）

GraphQL 的代价集中在服务端：它把复杂度从客户端搬到了服务端——而公开 API 是服务端买单。BFF 内部用 GraphQL、对外用 REST，是最常见的折中。
