12KB 记住一亿人

今天有 1 亿人访问了你的网站。统计独立访客数：HashSet 要 7.2GB，HyperLogLog 只要 12KB。代价是不到 1% 的误差——下面亲手验证这句话。

挑战

统计模块分到的内存预算是 64MB。选一个网站规模，把访客灌进去，数准他们。

本页模型说明

  • HashSet 按 Java HashMap 平均每条目约 72 字节计（16 字符 ID），不同语言量级相同。
  • Bitmap 需要连续整数 ID；真实访客 ID 是任意字符串，给字符串发号本身要先记住发过号的 ID——发号表就是另一个 HashSet。
  • HLL 参数 16384 桶 × 6bit，与 Redis 稠密编码一致，理论标准差 0.81%；本页用 32 位演示哈希，生产实现普遍用 64 位。
  • 全部计算在你的浏览器里完成，没有后端。

出处：Flajolet 等，HyperLogLog: the analysis of a near-optimal cardinality estimation algorithm, 2007；Redis PFCOUNT / PFADD 文档。
