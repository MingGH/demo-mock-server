时序放大镜：窗口在哪

机器内部在轮询循环里顺序做「检查挡板 → 使能射线」。两步之间有一段毫秒级空当—— 第二道命令若是从这条缝里挤进来，就会覆盖刚验证过的挡板位置。

0 ms（已锁）300 ms（大敞口）

竖轴浅色区块 = 能命中窗口的连打间隔范围。人类两秒连点通常落在 200ms 开外。

一行互斥锁：缝死窗口

修复方案朴素得反衬出悲剧的荒唐——把「检查挡板」和「开火」包进同一个原子动作， 让第二道命令要么排在检查前、要么排在开火后，独独没法插进中间。

修复前
// 伪代码 · 有竞态
if (blockerInPlace) {
    beam.power = dose;   // 此时被第二道命令覆盖
}
beam.fire();
修复后
// 伪代码 · 原子化
synchronized(lock) {
    if (blockerInPlace) {
        beam.power = dose;
    }
}
beam.fire();   // 检查与赋值之间，没人插得进手

复盘：这台机器为什么反复误杀

一句话教训

1985–1987 年累计 6 起超剂量事故，多人因过量辐射去世。 其根因并非操作员手快——竞赛总是它们的错——而是机器把「保命的安全判断」 托付给了纯软件里一个可被打断的瞬间。安全关键逻辑必须硬件冗余 + 原子化。
