先看懂：递归 CTE 给了 SQL 一个「循环」

普通 SQL 只会查数。加了 WITH RECURSIVE 之后，它能像程序一样反复执行自己——循环，是写任何游戏和图形算法的第一步。

递归 CTE 最小例子（数到 5）
WITH RECURSIVE t(i) AS (
    SELECT 1            -- 种子：第一行
    UNION ALL
    SELECT i + 1        -- 递归：拿上一行 +1
    FROM t
    WHERE i < 5         -- 终止条件
)
SELECT * FROM t;        -- 1,2,3,4,5
